# veggielocation
tldr: its a geoguessing guide for plants

i learned a ton about both css and geolocation while making this website, hope you enjoy!

## what it is
it's a website! with lots of info about vegetiation geolocation! more info under the info tab.

whats included in the website:

-info -> basic information about the site

-biomes -> helps make a broad estimate of the location based on the plants and enviornment

-agriculture -> identify common crops in the world and where they are grown

-misc metas -> some other things to know about plants that will help determine the location

-resources -> other stuff that will help with geolocation with plants

-practice -> five-location quiz with answer keys and explanations

## how to use
visit the website and click on different tabs to read the information. test out skills with some practice under the practice tab!
